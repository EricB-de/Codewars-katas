<h2><a href=https://www.codewars.com/kata/558878ab7591c911a4000007/train/typescript target="_blank">Single Word Pig Latin</a></h2><h3>6 kyu</h3><p>Pig Latin is an English language game where the goal is to hide the meaning of a word from people not aware of the rules.</p><p>So, the goal of this kata is to wite a function that encodes a single word string to pig latin.</p><p>The rules themselves are rather easy:</p><ol><li><p>The word starts with a vowel(a,e,i,o,u) -&gt; return the original string plus "way".</p></li><li><p>The word starts with a consonant -&gt; move consonants from the beginning of the word to the end of the word until the first vowel, then return it plus "ay".</p></li><li><p>The result must be lowercase, regardless of the case of the input. If the input string has any non-alpha characters, the function must return None, null, Nothing (depending on the language).</p></li><li><p>The function must also handle simple random strings and not just English words.</p></li><li><p>The input string has no vowels -&gt; return the original string plus "ay".</p></li></ol><p>For example, the word "spaghetti" becomes "aghettispay" because the first two letters ("sp") are consonants, so they are moved to the end of the string and "ay" is appended.</p>
